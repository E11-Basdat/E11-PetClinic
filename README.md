# File .env 
dikarenakan sebagian anggota langsung implementasi ke db, oleh karena itu berikut adalah file .env kami.
Create a `.env` file in the project root with the following variables:
```
USER=postgres.zpsdigoznzfwsfyjkyby
PASSWORD=petclinickelompoke11
HOST=aws-0-ap-southeast-1.pooler.supabase.com
PORT=5432
DBNAME=postgres


PGUSER=postgres.zpsdigoznzfwsfyjkyby
PGPASSWORD=petclinickelompoke11
PGHOST=aws-0-ap-southeast-1.pooler.supabase.com
PGPORT=5432
PGDATABASE=postgres

DJANGO_ENV=development
DATABASE_URL=postgresql://postgres.zpsdigoznzfwsfyjkyby:petclinickelompoke11@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres
```
